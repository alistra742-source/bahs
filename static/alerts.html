Discord webhook

Delivery

Sent straight from the server, never through your proxy list — a webhook URL is a capability and whoever runs a proxy would get it too. A webhook is not a dependency: a run never waits on one, and a failed post is counted, not retried into the run.

Free names are digested into batches so a wide sweep cannot hammer the endpoint into deleting the webhook. Placeholders: {username}, {platform}, {detail}.

Only names the run reports as free are alerted. An unconfirmed free name is still sent, and the message says so — an alert never presents a single exit's word as certain.
